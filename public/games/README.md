# Denty Games

Denty Games forma parte de Denty Paciente. No tiene registro ni alias propio.

- La identidad real es el paciente autenticado en Denty.
- El navegador nunca elige el nombre mostrado en rankings.
- La API muestra únicamente una etiqueta de ficha parcialmente oculta, por ejemplo `Ficha ••4281`.
- Récords y partidas se guardan por `patientId` en servidor.
- Air Hockey es local para dos jugadores y no participa en el ranking, aunque una partida válida puede contar para el bono de visita.
- El bono se activa cuando recepción confirma la llegada a sala de espera.

No añadir perfiles de juego locales, alias editables ni nombres clínicos al ranking.

# Denty · guía de microcopy

Objetivo: que el usuario entienda la siguiente acción en 1–2 segundos sin perder precisión clínica.

- Títulos visibles: 1–3 palabras siempre que sea posible.
- Botones: verbo directo (`Guardar`, `Firmar`, `Pedir cita`, `Jugar`).
- Descripciones: una sola idea y una sola línea; eliminar texto que repita el título.
- Errores: `qué pasó` + una acción útil. Evitar explicaciones técnicas en la primera capa.
- Campos: usar el sustantivo mínimo que mantenga el significado (`Odontólogo`, `Sede`, `Diente`).
- Detalle clínico/legal: conservar terminología exacta dentro del contenido o detalle, aunque la navegación sea breve.
- Accesibilidad: `aria-label`, títulos y textos no visibles pueden seguir siendo descriptivos; la poda se aplica sobre todo a la interfaz visible.
- Funciones avanzadas: se mantienen; se presentan bajo `Más`, `···`, acordeones o paneles contextuales.

Ejemplos aplicados:

- `Agenda operativa` → `Agenda`
- `Odontograma clínico` → `Odontograma`
- `Sincronización clínica` → `Sincronizar`
- `Presupuesto desde plan` → `Presupuesto`
- `Consentimientos firmados` → `Firmados`
- `Comunicar cambio médico` → `Actualizar salud`

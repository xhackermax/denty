| Carpeta | Contenido |
| --- | --- |
| [stages/](stages/) | Etapas 6–13: `*-HANDOFF` (qué se entregó), `*-PENDING-FINDINGS` (hallazgos y su estado), `*-VERIFICATION` (qué se comprobó). `CHECKPOINT-STATUS.md` resume el cierre de la etapa 13 |
| [releases/](releases/) | Notas de release (P3/P4, pagos multiproveedor, verificación) y migración a Node 24 |

Convención: un documento nuevo de etapa o release va a su carpeta con sufijo de fecha `AAAA-MM-DD`.

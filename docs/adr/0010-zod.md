# ADR 0010 · Zod

- Contexto: el proyecto actual confía en formas de datos no validadas y variables de entorno libres.
- Decisión: introducir Zod 4.6.5 desde F1 para `env.ts` y futuras fronteras API.
- Motivo: una única fuente de validación runtime + tipos inferidos.
- Alternativa descartada: casts TypeScript, que no validan datos reales.
- Consecuencia: F4 extenderá Zod a todos los contratos externos.

# ADR 0006 · stylelint-config-standard

- Contexto: Stylelint necesita una base coherente de reglas modernas.
- Decisión: usar `stylelint-config-standard` 40.0.0.
- Motivo: parte de convenciones modernas sin crear un reglamento propio enorme.
- Alternativa descartada: configurar cada regla desde cero.
- Consecuencia: las excepciones deberán ser explícitas y mínimas.

# ADR 0012 · @mantine/core

- **Estado:** aceptado · 2026-09-21.
- **Contexto:** Denty necesita una base accesible y consistente para formularios, overlays, navegación y layout.
- **Decisión:** Usar Mantine Core como kit UI base de F2. Versión exacta `9.6.1`.
- **Alternativas descartadas:** Componentes propios sin kit, MUI y Chakra.
- **Consecuencias:** Reduce CSS ad hoc y centraliza tema, foco, overlays y modo de color.
- **Revisión:** cualquier sustitución o salto incompatible exige un ADR nuevo.

# ADR 0018 · nuqs

- **Estado:** aceptado · 2026-09-21.
- **Contexto:** Pestañas y filtros deben ser enlazables y compatibles con atrás/adelante.
- **Decisión:** Usar nuqs para estado de UI persistido en la URL. Versión exacta `2.10.1`.
- **Alternativas descartadas:** useState aislado y parsing manual de searchParams.
- **Consecuencias:** Reduce estado duplicado y hace navegables los paneles.
- **Revisión:** cualquier sustitución o salto incompatible exige un ADR nuevo.

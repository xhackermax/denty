# ADR 0014 · @tabler/icons-react

- **Estado:** aceptado · 2026-09-21.
- **Contexto:** El producto legacy usa glifos Unicode inconsistentes y poco accesibles.
- **Decisión:** Usar iconos Tabler importados por icono. Versión exacta `3.47.0`.
- **Alternativas descartadas:** Unicode, SVG copiados y otros packs completos.
- **Consecuencias:** Los iconos pasan a ser semánticos, consistentes y tree-shakeables.
- **Revisión:** cualquier sustitución o salto incompatible exige un ADR nuevo.

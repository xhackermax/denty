# ADR 0017 · next-intl

- **Estado:** aceptado · 2026-09-21.
- **Contexto:** Todos los textos de interfaz deben salir de diccionarios tipados y quedar preparados para más idiomas.
- **Decisión:** Usar next-intl con es activo y Server Components por defecto. Versión exacta `4.14.2`.
- **Alternativas descartadas:** Cadenas literales y soluciones i18n propias.
- **Consecuencias:** El locale, zona horaria y mensajes quedan centralizados desde F2.
- **Revisión:** cualquier sustitución o salto incompatible exige un ADR nuevo.

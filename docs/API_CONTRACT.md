## Reglas de frontera

- Todas las respuestas deberán validarse con zod en `shared/api/schemas`.
- `401`, `403`, `409` y errores 5xx tendrán tipos explícitos.
- Mutaciones críticas usarán `Idempotency-Key`.
- No se añadirá un endpoint nuevo desde el frontend sin documentarlo primero como `INFERIDO`/gap.
- Adjuntos deben migrar de base64-en-JSON a multipart o URL prefirmada cuando el backend lo soporte.

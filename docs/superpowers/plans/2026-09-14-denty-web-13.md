# Denty Web 1.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Avanzar Denty Web desde 0.7 hasta una preview 1.3 con persistencia/recovery, planificación clínica, consentimientos robustos, importación segura y NLU dental básica.

**Architecture:** Mantener app estática Vercel + localStorage. Añadir funciones puras en `logic.js`, conectarlas mínimamente en `app.js`, documentar límites en `README.md` y verificar con `verify_preview_13.mjs`.

**Tech Stack:** JavaScript ESM, HTML, CSS, localStorage, ZIP estático para Vercel.

**Spec:** Solicitud del usuario: avanzar roadmap hasta 1.3 sin prometer equivalencia con APK SQLite/Vosk/knowledge-v3.

## Global Constraints
- No backend real, no SQLite real y no Vosk real en esta preview.
- Mantener logo real de la APK.
- Mantener Vercel Drop compatible.
- Toda nueva función principal debe estar cubierta por `verify_preview_13.mjs`.

---

### Task 1: Recovery y almacenamiento seguro
- Crear pruebas para `createRecoverySnapshot`, `recoverDbFromSnapshots`, `safeSaveDb`, `validateStorageHealth`.
- Añadir implementación mínima en `logic.js`.
- Cambiar `persist()` en `app.js` para usar `safeSaveDb`.

### Task 2: Planificación clínica 1.3
- Crear pruebas para `CLINICAL_PHASES`, `classifyTreatmentPriority`, `createTreatmentPlan`, `schedulePlanStep`.
- Añadir generación de pasos jerárquicos por fase, prioridad y plazo.

### Task 3: Consentimientos y firma 1.3
- Crear pruebas para `CONSENT_DEFINITIONS`, `prepareConsentDocument`, `signConsentWithAudit`.
- Exigir aceptación explícita antes de firma.
- Guardar hash, auditoría y versión.

### Task 4: Importación segura
- Crear pruebas para `validatePatientImportRows`.
- Detectar filas inválidas, duplicados y advertencias.

### Task 5: NLU dental mínima
- Crear pruebas para `parseDentalCommand` y `applyDentalCommand`.
- Soportar caries por superficie, periodontal por texto, presupuesto de implante y agenda de tratamiento.

### Task 6: UI y documentación
- Actualizar etiquetas a 1.3.
- Añadir menciones visibles a Recovery, Importación segura, NLU dental, planificación clínica y consentimientos definidos.
- Verificar sintaxis, tests, ZIP y SHA.

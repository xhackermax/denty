Reglas de compatibilidad
- No se fija una versión menor/parche de Node en Vercel: 24.x permite las actualizaciones de mantenimiento de la plataforma.
- No se fuerza npm a una versión exacta para evitar acoplar el proyecto a un parche concreto del build image.
- No se añade runtime manual por función: las funciones Next.js usan el runtime Node del proyecto; las rutas que lo requieren pueden declarar runtime="nodejs".
- package.json engines.node es la fuente de verdad de la versión Node del despliegue.
